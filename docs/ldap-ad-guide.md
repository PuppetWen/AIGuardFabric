# LDAP / Active Directory 登录接入

本功能用于让企业成员用目录账号登录平台。个人用户继续使用本地账号；已有 OIDC 的企业可继续使用 OIDC。LDAP 服务账号只负责查询，成员口令由目录服务验证，平台不保存成员口令。每个租户独立配置，目录账号不会按邮箱合并本地管理员。

1. 在 AD 或 OpenLDAP 建立只能读取目标用户 OU 的服务账号，记录其完整 DN 和口令。优先给平台单独的服务账号，并限制它的查询范围。
2. 为目录服务配置可信证书，证书的 DNS 名称须与连接地址一致。在「设置 → LDAP / AD」填写 `ldaps://ad.example.com:636`；若服务器仅提供 LDAP 389，则填写 `ldap://ad.example.com:389` 并开启 StartTLS。无法验证的证书不会被接受。企业私有 CA 可将 PEM 证书粘贴到 CA 字段；不要上传私钥。
3. 填写用户搜索根 DN 和过滤器。AD 常用搜索根 `ou=People,dc=example,dc=com`、过滤器 `(&(objectClass=user)(sAMAccountName={username}))`、唯一 ID 属性 `objectGUID`；OpenLDAP 常用 `(&(objectClass=person)(uid={username}))` 和 `entryUUID`。过滤器必须且只能包含一个 `{username}`，平台对成员输入做 LDAP 过滤器转义。查询不到、命中多个对象或没有唯一 ID 时均拒绝登录。
4. 先用「首次目录登录自动创建账号」与「只读用户」角色测试。平台以目录地址和不可变 ID 建立账号映射，改动这两项不会自动迁移已有账号。确认登录后可由管理员调整角色。若关闭自动创建，仅已经纳管的目录账号可登录。
5. 用户在登录页输入租户标识、目录用户名、目录口令，点击「LDAP / AD 登录」。若平台要求 MFA，继续填写平台验证码；若租户强制 MFA 但成员未绑定，只能进入 MFA 绑定流程。平台停用或锁定账号后，目录口令即使正确也不能登录。

排障：证书或连接失败时，核对 DNS、网络、证书信任链和 CA PEM；查找失败时核对搜索根、只读服务账号权限及过滤器；账号拒绝时检查唯一 ID、目录账号状态、平台账号状态与是否允许首次创建。API 错误不会返回目录服务的私有错误详情。生产前先在测试租户使用真实目录测试，再让成员分批切换。

接口：`GET/PUT /api/v1/settings/identity/ldap` 需要设置权限，写入需携带当前 `expected_revision`；`POST /api/v1/auth/ldap/login` 为公开登录入口。目录配置变更时登录请求会失败关闭，用户可重新发起。外部目录不可用时不会回退到本地口令或演示数据。
