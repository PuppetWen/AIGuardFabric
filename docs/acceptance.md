# 公开版本验收范围

本文件提供公开版本的状态说明，不包含部署现场的账号、证据目录、数据库或私密请求响应。

已验证的范围是：一台 Windows 主机上的 Docker Linux 容器本地自托管部署，以及 11 项真实文本模型功能链路。功能样本包括一个已有 Internal 告警和一个明确创建的合成案件，不能据此证明真实安全设备的因果接入、模型研判准确率或所有安全指标。

跨平台部署入口使用 `linux/amd64` 容器。Windows、Linux/Ubuntu 和 macOS 的安装方法见 [跨平台部署](portable-deployment.md)。入口的配置与初始化检查不等于所有这些操作系统都已完成实机验收，Apple Silicon 采用仿真而非原生 ARM64 构建。

仍保留的未通过或未验证项目：

- 最新 10k 负载测试未通过；当前版本未完成 1,000 并发查询验收。
- 12 小时长稳被取消，不存在持续稳定性通过结论。
- 红队语义质量和安全 CI 尚未全部通过；视觉模型能力未验。
- 阿里云真实资源联调未验，本地模拟不代替真实云。
- 备份业务覆盖检查与全内部关系严格恢复比较存在不同边界；不宣称所有 Timescale 内部历史关系均已完整复原。

后续验证应使用独立测试环境和自己的接入凭据，保留失败记录，不能把 Mock、配置校验或镜像准备标为真实业务验收。
