# MSE 服务盘点

本功能调用公开只读 API `ListAnsServices`，把服务名称、分组、实例数、健康实例数、集群数和来源发布到本地资产台账。资产类型为 Other；接口没有返回 MCP/Skill 元数据、地址、协议、运行环境、网络区域或授权证据，这些云观察保持未知。新资产使用平台的默认分类和生命周期，默认值不是云端证明。人工治理字段、名称、类型、负责人、标签和自定义属性均保留。

## 接入

1. 在阿里云连接中选择 MSE，配置 region_id、instance_id 和 namespace_id。必须显式填写 namespace_id；空字符串表示默认命名空间。端点和凭据使用现有连接配置。凭据需要允许 ListAnsServices，不要求服务写权限。
2. 先使用 Mock 模式验证流程。Mock 回执、快照和资产均带明确标识，不会调用云端。切换到真实模式后需要重新盘点；旧 Mock 观察不会显示为真实资产清单。
3. 平台操作者需有 alicloud:read、alicloud:write、assets:write。真实盘点还要显式确认只读云请求。
4. 发布成功后通过服务的 assetId 打开资产台账，补充人工治理。仅 alicloud:read 即可查看盘点及原请求回执，不会触发云请求。

## 请求与回执

`POST /api/v1/alicloud/mse/inventory/sync`

```json
{"request_id":"填入新UUID","configuration_version":1,"confirm_live":true}
```

每次明确的新盘点使用新 UUID。相同请求和参数只返回已有回执，不再次发送读取；改变参数或范围却复用编号返回409。正在运行的同范围请求拒绝另一个盘点。主请求台账有512条/4MiB上限，可通过下方归档操作释放已结束请求的槽位。

`GET /api/v1/alicloud/mse/inventory` 返回当前配置范围的清单、主台账最近50条请求摘要（包含active请求）、generation 和累计 archivedCount。列表不扫描归档历史；旧编号可单独查询。当前配置无快照时 inventoryAvailable=false、totalServices=null；已完整观察且没有服务则 true、0。缺失计数为 null，明确0为真实观测到的零。

`GET /api/v1/alicloud/mse/inventory/operations/{request_id}` 只读原回执。published 表示该请求曾原子发布成功；current 仅表示原配置范围仍为当前范围，不能证明这个旧请求仍是最新一轮。

`POST /api/v1/alicloud/mse/inventory/operations/{request_id}/cancel` 使用空对象 `{}`，停止下一页及最终发布。停用或换版连接后仍可以本地取消。已经发送的只读请求不能撤回。关闭页面或断线不等于取消；请求可能继续完成，也可能停留至租约过期，使用原编号查询确认状态。

## 释放请求台账容量

1. 读取盘点列表的 generation，选择 archivable=true 的已结束请求。仅租约过期、页面显示 interrupted 的原 running 请求不能直接归档，先用取消接口结束它。
2. `POST /api/v1/alicloud/mse/operations/archive`，一次明确提交1至100个唯一 UUID：

```json
{"expected_generation":42,"request_ids":["填入已结束请求UUID"]}
```

3. 响应返回新 generation、累计 archivedCount 和本次确认的 archivedRequestIds。409表示台账已变化，需要重新读取后再次明确选择；不会自动改版本重发。归档需与盘点相同的三项平台权限，连接停用后仍可执行本地归档。

归档将原终态回执移入独立永久领取记录，与主台账和审计同事务提交；当前快照及所有资产完全不变。单独查询旧编号返回 status=archived、originalStatus 原终态、archivedAt 和原 published 证据。相同原请求只返回归档回执，永不再次发送云请求；配置或参数已变化时返回409并说明编号不能重派。领取事实不会自动删除，归档不等于清除幂等保护，也不撤销曾经发布的资产观察。

## 完整性和失败恢复

最多20页，每页100条、2000项、110秒；租约120秒。页总数改变、缺页、重复服务、坏类型、范围不符、权限撤销、租约或取消状态改变均停止发布，原快照保留。列表完整只表示按该公开接口完成本次分页，不能保证云端多页强一致快照。服务在此次完整清单中未出现，仅标记来源未观察，不删除、不归档、不改变人工生命周期。

范围绑定配置版本、配置来源摘要、地域、实例、命名空间及 Mock 模式；摘要不是已经验证的 RAM 账号身份。改配置后旧快照保留但不会冒充新账号当前清单。普通配置换版且来源身份未变时，同一服务的资产 ID 不变，人工治理保留。

发布把来源观察、加密快照、最终请求状态和成功审计放在同一事务。审计或数据库失败不发布部分数据；失败详情不存原始云响应、凭据或任意元数据。已经由用户删除的资产不自动复活，整批返回409并保留原快照；需要用户先显式恢复或核对资产，再用新编号盘点。

PostgreSQL 支持跨实例领取、归档和原子发布；最终发布在资源锁等待后再次读取当前权限和原提交账号安全状态。无数据库模式仅单进程内存，重启会丢失配置、快照、请求及归档事实。离线操作在提交时及每次云派发前校验身份，最终短同步内存提交不跨await刷新身份，也不承诺跨进程协调。失败、取消、interrupted 或 superseded 的旧编号不能重新派发，可在确认当前配置后用新 UUID 发起新的只读盘点。

本期不发布或回滚 MSE 配置，不创建/修改/删除云服务，不把 Md5 当作未经证明的并发写入保证，也不实现 APIG/PrivateLink 网络写操作。
