# Report font

`NotoSansCJKsc-Regular.otf` is the unchanged Noto Sans CJK SC Regular font from the upstream Sans2.004 release, licensed under SIL OFL 1.1. Copyright notices remain inside the font; `OFL.txt` accompanies it. The font is compiled into the server, so report generation requires no OS font installation or network connection.

Exports embed a glyph subset and a Unicode map, preserving Chinese text when copying or searching. The subsetter retains font copyright metadata. Glyphs outside this font's coverage use its missing-glyph outline; original Unicode text remains in the PDF text map. Emoji color rendering and complex-script shaping are outside this font's scope.
